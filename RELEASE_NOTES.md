# XML2 32 Roster Hack - Beta v0.01

First beta release.

**Included in the zip:** `rosterhack.asi`, `rosterhack.ini`, `README.txt`, and an optional `controllerchain.asi` for XML2 Modern Controller v0.5.0-beta.2 (see the readme).

**Not included (download separately):**
- Ultimate ASI Loader v10.0.0 (`Ultimate-ASI-Loader-NoPDB.zip`): https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases. See the readme for how to extract and rename it.
- XML2 Modern Controller v0.5.0-beta.2, if you use it: https://github.com/andreMeloo/XML2-Modern-Controller/releases
- Character mods, individually or as packages (such as AXE, BHE and MUE), from the Marvel Mods forum: https://marvelmods.com/forum/index.php/topic,753.0.html

**What it does:** raises the hero limit of the 2005 PC version of X-Men Legends II to 32 hero slots (31 playable plus the default entry), fixes portraits for the 22nd hero and beyond, and enlarges the character pool and name table so cutscene characters and NPC versions of heroes still appear.

**Tested:** new game, cutscenes, first mission, first hub, stash, store, review terminal, save and load, with 32 heroes. Tested with a direct install only (files copied into the game folder), not through a mod organizer.

**Not yet tested:** Mod Organizer 2 (it uses a virtual file system, so the log and ini may end up in a different place), Danger Room, long missions, swapping the default man in every situation, and other limits in the game or herostat that this plugin doesn't change.

**Known issues:** OpenHeroSelect (OHS and OHSGUI) from the Marvel Mods forum does not work with the roster hack in its current form. Executables included with some character packages may not work with the roster hack either.

Please report problems in Issues and attach `xml2_roster.log` and `rosterhack.ini`.
